# IEEE and ACM Writing Route

Check the current official template, article type, page policy, anonymization policy,
artifact policy, and AI disclosure rules for the exact venue. Do not apply a universal
reference count, page count, or section order.

Common IEEE-oriented elements include an abstract, index terms, introduction, related
work, method, experimental setup, results, discussion, conclusion, acknowledgments,
and references. Common ACM-oriented elements additionally include CCS concepts and a
dedicated threats-to-validity section. The venue may combine or rename sections.

For CS and engineering papers:

- state research questions before evaluation;
- describe datasets, tasks, baselines, metrics, software, hardware, and hyperparameters;
- report uncertainty and repeated-run policy;
- connect each ablation to a contribution claim;
- discuss failure cases and internal, construct, external, and conclusion validity;
- keep captions understandable without unsupported interpretation;
- preserve anonymous-review requirements in author fields, self-citation wording,
  repository links, acknowledgments, and PDF metadata.

Use the official IEEE or ACM BibTeX and LaTeX material supplied by the user or venue.
The bundled generic template is a drafting scaffold, not an official submission class.
